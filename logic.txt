def statusand_risk(total: float, limit: int) -> tuple[str, float, int]:

* нет лимита (0)         -> считаем 'normal', риск 0 (не с чем сравнивать);
* расход >= 125% лимита  -> 'danger'  (существенный перерасход);

return "danger", 999.0, 100

if ratio >= 1.25:
status = "danger"
elif ratio >= 1.0:
status = "warning"
else:
status = "normal"
risk = max(0, min(100, round(ratio * 100)))
return status, round(ratio, 3), risk

"""Подсказать «круглый» лимит под фактический расход, с запасом ~10%.
